新增与 PixelMiPushFramework 协作的运行状态接口，并开放 QQ 通知定制的独立控制。

## 新功能

- **状态联动**：配套框架可检查推送服务和系统通知增强是否就绪，并确认设置已同步
- **QQ 独立选项**：角标、会话头像布局和汇总副标题清理分别控制，设置保存在模块侧并同步到相关进程

## 改进

- **布局切换**：关闭头像定制后，后续视图绑定恢复原有尺寸与边距，避免复用视图保留定制布局

请与 PixelMiPushFramework v1.2.0 配套使用模块设置。同包名、同签名可覆盖更新，更新后按模块管理器提示重启，API 102 与长期签名保持不变。

当前样本未复现汇总通知的重复副标题，不据此认定所有系统均已替代这项处理。

详细接口与验证边界见 [模块控制](https://github.com/huaxianyan/PixelMiPush/blob/v1.1.0/docs/MODULE-CONTROL.md)。
