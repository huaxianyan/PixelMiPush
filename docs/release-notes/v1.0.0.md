模块从 1.0.0 开始使用独立版本号。本版修复 Android 17 上 QQ 推送通知归属错误，并提供 Obtainium 更新入口。

## 新功能

- **Obtainium 更新**：可从 README 导入模块，跟踪后续正式版本。

## 改进

- **Android 17 目标版本**：targetSdk 提升至 37。同为 1.0.0 的更新包将 versionCode 提升至 245，可覆盖此前正式包。

## 问题修复

- **Android 17 通知归属**：修复 QQ 推送通知归属「推送服务」、显示推送服务图标的问题，恢复按 QQ 身份发布通知。

包名改为 `com.neko7ina.pixelmipush`。旧包用户须先关闭旧模块，再安装新模块、重选 LSPosed 作用域及模块私有配置，最后手动重启。确认正常后再卸载旧包，推送服务及其配置文件保持原位。

此前 targetSdk 34 的测试包已在 Android 17 上验证 QQ 历史消息重新发送。本次 targetSdk 37 更新包尚未完成设备回归。低版本调用语义保持一致，但本轮未在低版本设备重新实测。

完整记录见 [Pixel API 102 说明](https://github.com/huaxianyan/PixelMiPush/blob/v1.0.0/PIXEL-API102.md)。
